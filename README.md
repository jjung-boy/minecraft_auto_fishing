# Minecraft 자동 낚시 (Java Edition, Windows)

자막 영역을 캡처해서 `Fishing Bobber splashes` 자막이 뜨면 우클릭으로 낚고 다시 던집니다.

> 멀티플레이 서버는 대부분 매크로를 금지합니다. 싱글플레이나 허용된 서버에서만 쓰세요.

## 설치

1. Python 3.10 이상 설치 (설치할 때 "Add python.exe to PATH" 체크)
2. 이 폴더에서:

```bash
pip install -r requirements.txt
```

## 게임 준비

- 설정 > 접근성 > **자막 표시: 켬**
- 게임 언어가 한국어면 자막이 `낚시찌가 첨벙거림`처럼 나옵니다. 템플릿은 화면에 보이는 그대로 캡처하니 어떤 언어든 상관없지만, **템플릿을 만든 뒤 언어·GUI 크기·창 크기를 바꾸면 다시 캡처**해야 합니다.
- 전체화면(F11)보다 **창 모드**가 편합니다. 설정 중에 영역 지정 창이 게임 위에 떠야 하기 때문입니다.
- `F3 + P` 를 눌러 "창 전환 시 일시정지"를 꺼두면 좋습니다.

## 실행

```bash
python autofish.py
```

처음 실행하면 설정을 진행합니다.

1. **자막 영역 지정**: 낚싯대를 던져 자막을 띄우고 게임에서 `F9` → 뜨는 창에서 자막 상자가 나오는 범위를 넉넉히 드래그하고 `Enter`
2. **템플릿 캡처**: `Fishing Bobber splashes` 자막이 뜬 순간 `F9` → 글자 부분만 딱 맞게 드래그하고 `Enter` (좌우 `<` `>` 화살표는 빼기)

영역은 `region.json`, 템플릿은 `template.png` 에 저장되고 다음부터는 바로 시작합니다.

이후 조작:

| 키 | 동작 |
|---|---|
| `F8` | 시작 / 정지 (시작하면 바로 한 번 던짐) |
| `F10` | 프로그램 종료 |

시작할 때는 낚싯대를 손에 들고, 찌가 회수된 상태여야 합니다.

다시 설정하기:

```bash
python autofish.py --setup
```

`--region` 은 영역만(템플릿도 이어서 다시 캡처), `--template` 은 템플릿만 다시 지정합니다.

## 설정 (`config.json`)

| 키 | 기본값 | 설명 |
|---|---|---|
| `match_threshold` | `0.8` | 이 점수 이상이면 입질로 판단 |
| `reaction_delay` | `[0.2, 0.6]` | 감지 후 회수까지 랜덤 지연(초) |
| `recast_delay` | `[1.0, 2.0]` | 회수 후 재투척까지 랜덤 지연(초) |
| `bite_timeout` | `30` | 이 시간 동안 입질이 없으면 회수 후 재투척(초) |
| `cast_grace` | `3.5` | 투척 직후 이 시간 동안은 감지 무시. 이전 입질 자막과 "Fishing Bobber thrown" 자막이 약 3초간 남아 있어서 |
| `scan_interval` | `0.05` | 캡처 간격(초) |
| `log_interval` | `1.0` | 매칭 점수 로그 주기(초). 구간 내 최고 점수를 찍음 |
| `click_backend` | `"pyautogui"` | `"pydirectinput"` 으로 바꿀 수 있음 |
| `click_hold` | `[0.04, 0.09]` | 우클릭을 누르고 있는 시간(초) |
| `toggle_key` / `capture_key` / `quit_key` | `f8` / `f9` / `f10` | 핫키 |
| `monitor_index` | `1` | 영역 지정 시 캡처할 모니터 (1 = 주 모니터) |
| `binarize` | `false` | `true` 면 흰 글자만 남기고 매칭 (배경이 자주 바뀌어 점수가 흔들릴 때) |
| `binarize_level` | `180` | 이진화 기준 밝기 |

## 임계값 맞추기

로그에 1초마다 `매칭 점수 최대 0.xxx` 가 찍힙니다.

- 입질이 없을 때 점수와 입질 자막이 떴을 때 점수를 보고 그 사이로 `match_threshold` 를 정하세요.
- 입질을 놓친다 → 임계값을 낮추거나 템플릿을 다시 캡처
- 엉뚱할 때 낚는다 → 임계값을 높이거나, 템플릿을 `splashes` 단어 위주로 다시 캡처 ("Fishing Bobber thrown" 과 앞부분이 같아서 점수가 0.8 근처까지 나올 수 있음)

## 문제 해결

- **클릭이 게임에 안 먹힘**: `pip install pydirectinput` 후 `config.json` 의 `click_backend` 를 `"pydirectinput"` 으로. 그래도 안 되면 터미널을 관리자 권한으로 실행.
- **F8 이 안 먹힘**: `keyboard` 라이브러리는 게임이 관리자 권한으로 실행 중이면 키를 못 받을 수 있습니다. 터미널도 관리자 권한으로 실행하세요.
- **영역이 엉뚱한 곳을 캡처**: 디스플레이 배율을 바꿨거나 창을 옮겼다면 `--setup` 으로 다시 지정.
