마인크래프트 자동 낚시 사용방법
==============================

※ 싱글플레이 전용으로 쓰세요. 멀티 서버는 대부분 매크로 금지라 계정이 밴될 수 있습니다.


[1] 처음 한 번만: 설치
----------------------
1. Python 설치: https://www.python.org/downloads/
   - 설치 첫 화면 아래 "Add python.exe to PATH" 를 꼭 체크!
2. 이 폴더의 "설치.bat" 더블클릭 → 검은 창에 "Done!" 이 나오면 끝


[2] 마인크래프트 준비
--------------------
1. Esc → 설정 → 접근성 → 자막 표시: 켬
2. 전체화면이면 F11 눌러서 창 모드로
3. F3 + P 눌러서 "창 전환 시 일시정지" 끄기
4. 물가에서 낚싯대 들기


[3] 처음 한 번만: 영역/자막 등록
------------------------------
"실행.bat" 더블클릭 → 검은 창의 안내를 따라 하면 됩니다.

① 자막 영역
   - 낚싯대를 던져서 오른쪽 아래에 자막이 보이게 하고 F9
   - 뜨는 창에서 자막 나오는 곳을 위아래로 넉넉하게 드래그 → Enter

② 입질 자막
   - "낚시찌가 첨벙거림" (영어면 "Fishing Bobber splashes") 자막이 뜨면 F9
   - 뜨는 창에서 글자 부분만 딱 맞게 드래그 → Enter
     (양옆 < > 화살표는 빼기)


[4] 낚시하기
-----------
"실행.bat" 더블클릭 → 마인크래프트 화면 클릭 → 낚싯대 들고:

   F8  : 시작 / 정지
   F10 : 프로그램 끄기
   F7  : 지금 화면 점수 확인 (안 낚일 때 원인 확인용)

시작할 때는 찌를 회수한 상태로 시작하세요.


[문제 해결]
----------
- 안 낚임 / 엉뚱하게 낚음
  → "다시설정.bat" 으로 영역과 자막을 다시 등록
  → 마인크래프트 창을 옮기거나 크기, GUI 크기, 언어를 바꿨으면 꼭 다시 등록

- 검은 창 로그에 "임계값 근처 점수 0.7xx" 가 뜸
  → config.json 을 메모장으로 열어 "match_threshold" 를 0.7 로

- 검은 창 로그에 "투척 직후 ... 감지 무시" 가 뜸
  → config.json 의 "cast_grace" 를 2.0 으로

- 클릭이 게임에 안 먹힘
  → 명령 프롬프트에서  pip install pydirectinput
  → config.json 의 "click_backend" 를 "pydirectinput" 으로

- F8 이 안 먹힘
  → 실행.bat 을 우클릭 → 관리자 권한으로 실행

- "[ERROR] Python not found" 가 뜸
  → Python 을 다시 설치하면서 "Add python.exe to PATH" 체크

- "[ERROR] Required packages are not installed" 가 뜸
  → 설치.bat 을 먼저 더블클릭해서 "Done!" 이 나올 때까지 기다리기
